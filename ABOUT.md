# Who I am and why this project

I'm Bar, an undergraduate student in Information Systems. This project is my **final year project** for the degree.

## My goal

- Build a final project with **high-quality code** — not just "working", but properly structured and professional, the way it's done in industry.
- **Understand and know every part of the system** myself — not receive a black box. When meaningful code is added (especially business logic or algorithms), I want it explained to me, not just written.
- Clean, readable code: organized structure, meaningful names, separation of concerns (Clean Architecture) — so I can read my own project and explain it to an advisor/examiner.

## The project

A study-planning system for exam prep — it turns simple scheduling into a learning methodology tool: it identifies topics from study material, builds a schedule that accounts for my time constraints and my mastery level per topic, emphasizes weak topics in the review session before the exam, and supports Study Groups so classmates can share a topic backlog while keeping personal schedules, grades, and constraints private.

The full requirements live in [CLAUDE.md](CLAUDE.md) — the specification document that guides every work session with the agent on this project.
